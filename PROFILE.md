# Neutrino API

A general-purpose API collection solving common software-development problems including data validation, telephony, geolocation, security/networking, e-commerce, and imaging. Exposes a REST-style HTTP API with selectable multicloud (AWS/GCP/Azure) endpoints, authenticated via user-id + api-key.

## APIs

- **Neutrino API** — RESTful-style HTTP API accepting GET/POST requests, authenticated with user-id + api-key. Covers telephony, geolocation, security/networking, e-commerce, imaging, and data tools, with a batch /multi endpoint. (`https://neutrinoapi.net/`)

> Public REST-style API at https://neutrinoapi.net/ with multicloud/regional endpoints (AWS/GCP/Azure) documented at https://www.neutrinoapi.com/api/multicloud/. Authentication is user-id + api-key. Machine-readable contracts (OpenAPI 3.1, Swagger 2.0, Postman, Insomnia, RAML, WADL, WSDL, API Blueprint) are advertised on the specification page and via the APIMATIC portal at https://neutrinoapi.apimatic.dev, though provider host blocked automated fetching so live byte content of spec files was not independently downloaded. No agent-native surfaces found: no hosted or local MCP server, no llms.txt, and no published agent skills on neutrinoapi.com or its GitHub org.
